# CS-465: Full Stack Development

## Overview
This project involved building Travlr Getaways, a full-stack travel booking site, using the MEAN stack (MongoDB, Express, Angular, and Node.js). The work was completed incrementally across multiple modules, building out the front-end client, back-end API, and database layer.

## Approach
I built the application in stages, starting with a static front-end design and progressively adding dynamic content, RESTful API endpoints, and database integration. Each module built on the previous one, layering in user authentication, server-side rendering, and data persistence as the application matured into a complete full-stack site.

## Reflection
This project deepened my understanding of how the different layers of a web application, the database, server, and client, work together as a cohesive system. Working through each module's requirements reinforced the importance of testing each layer independently before integrating it with the rest of the stack, which made debugging issues across the front end and back end much more manageable.

## Skills Demonstrated
- Full-stack development with the MEAN stack
- RESTful API design
- MongoDB schema design and data modeling
- Angular front-end development
